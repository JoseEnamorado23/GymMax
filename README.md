# GymMax 💪

Sistema integral de gestión para gimnasios locales, construido con tecnologías modernas para asegurar rapidez y facilidad de uso.

## Tecnologías Utilizadas

- **Backend:** Python, FastAPI, SQLAlchemy, PostgreSQL.
- **Frontend:** React, Vite, CSS moderno con enfoque Glassmorphism.
- **Base de Datos:** PostgreSQL corriendo en Docker.

## Funcionalidades Actuales
- 👥 **Módulo de Usuarios:** Registro, edición y listado de miembros del gimnasio.
- 📋 **Módulo de Planes:** Creación de planes de entrenamiento (mensualidades, tiqueteras) con precios y duración.
- 💰 **Módulo de Ventas:** Asignación directa de planes a los usuarios desde la plataforma.
- 📷 **Módulo de Recepción (QR):** Portero inteligente para validar entrada de usuarios activos y negar el paso a mensualidades vencidas.
